# 🖥️ PC Builder Expert System

Sistema especialista para montagem de PCs, com validação de compatibilidade de componentes em tempo real e orientação de orçamento.

## 📋 Sobre o Projeto

Este projeto tem como objetivo auxiliar usuários na montagem de computadores, verificando automaticamente a compatibilidade entre componentes (placa-mãe, processador, memória, fonte, etc.) e oferecendo orientações de acordo com o orçamento disponível.

## ✨ Funcionalidades

- ✅ Validação de compatibilidade de componentes em tempo real
- ✅ Orientação de orçamento durante a montagem
- ✅ Interface reativa e responsiva
- 🔜 Integrações adicionais (em desenvolvimento)

## 🛠️ Tecnologias

- [Angular](https://angular.dev/) — Standalone Components
- TypeScript
- Padrões reativos (RxJS)

## 📦 Pré-requisitos

- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [Angular CLI](https://angular.dev/tools/cli)

```bash
npm install -g @angular/cli
```

## 🚀 Instalação

```bash
# Clone o repositório
git clone https://github.com/<usuario-ou-org>/<nome-do-repo>.git

# Acesse a pasta do projeto
cd <nome-do-repo>

# Instale as dependências
npm install
```

## ▶️ Executando o projeto

```bash
ng serve
```

Acesse `http://localhost:4200/` no navegador. A aplicação recarrega automaticamente ao salvar alterações nos arquivos.
